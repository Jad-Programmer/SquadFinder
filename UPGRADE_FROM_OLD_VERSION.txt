DISCORD-INSPIRED THEME UPDATE

This update changes the interface only and keeps the 12-game / 48-map catalog and all existing functionality.

METAVERSE SQUADFINDER UPDATE INSTRUCTIONS

1. Close the old SquadFinder window and command prompt.
2. Open the old SquadFinder folder.
3. Copy the complete "instance" folder.
4. Paste it inside this new "metaverse_squadfinder" folder.
5. Confirm that this file exists:
   instance\squadfinder.db
6. Double-click START_WINDOWS.bat.

Your old database is preserved. The app automatically inserts only the newly
added built-in games and maps that are missing.


CHAT + VOICE UPDATE
- Existing instance/squadfinder.db files are upgraded automatically.
- New room_messages, voice_presence, and voice_signals tables are added without replacing existing data.
- Use START_WINDOWS.bat for the full app, text chat, and voice through trusted HTTPS.
- The old START_WINDOWS_VOICE_HTTPS.bat now opens the same trusted launcher.

NEW IN THIS VERSION:
- Visible Add Real Game Map button for all signed-in users.
- Requires the exact in-game code/ID/URL/server address.
- Rejects placeholders and duplicate codes.
- Community submissions are unverified until checked.
- First successful map submission unlocks the creator console.


TRUSTED HTTPS UPDATE
- The default URL is now https://localhost:5443.
- The launcher generates a private local CA on this computer and trusts its
  public certificate for the current Windows user.
- Do not use the old http://127.0.0.1:5000 address.
- If a browser was already open during setup, close all browser windows once
  and start SquadFinder again.
- The certificate files are stored under the Windows user's LOCALAPPDATA and
  are separate from instance\squadfinder.db.
