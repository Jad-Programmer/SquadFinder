METAVERSE SQUADFINDER — TRUSTED HTTPS UPDATE
============================================

The app no longer starts with Werkzeug's temporary self-signed certificate.
START_WINDOWS.bat now:

1. Generates a private SquadFinder local certificate authority on your computer.
2. Adds only its public certificate to the current Windows user's trusted roots.
3. Generates a server certificate for localhost, 127.0.0.1, the computer name,
   and the active LAN IP addresses.
4. Starts the app at https://localhost:5443.
5. Enables Secure/HttpOnly session cookies, a Content Security Policy,
   and additional browser security headers.

The CA private key remains inside:
%LOCALAPPDATA%\MetaVerseSquadFinder\trusted_https\squadfinder_local_ca_key.pem

Do not share that private key. It is generated locally and is not included as a
pre-generated certificate in this ZIP.

FIRST START
-----------
Double-click START_WINDOWS.bat and use exactly:
https://localhost:5443

The old URL http://127.0.0.1:5000 is intentionally no longer the default.

If the browser was open while Windows trust was installed, close every browser
window once and start the app again. Normally, because trust is installed before
the browser is opened, the red "Not secure" warning will not appear.

OTHER COMPUTERS OR PHONES
-------------------------
Every separate device must trust the public CA certificate before it can show a
trusted lock for a LAN-IP URL. The public certificate is:
%LOCALAPPDATA%\MetaVerseSquadFinder\trusted_https\squadfinder_local_ca.cer

Only install this public .cer on devices you control. Never copy the *_key.pem
files to another device.

PUBLIC INTERNET
---------------
For a public production service, use a real domain and a publicly trusted TLS
certificate through a reverse proxy or hosting provider. The local CA mode is
intended for your own Windows computer and trusted private-network devices.

REMOVAL
-------
Run REMOVE_SQUADFINDER_LOCAL_CERTIFICATE.bat to remove SquadFinder's local CA
from the current Windows user's trusted-root store.
