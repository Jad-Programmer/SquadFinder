REAL GAME MAP SUBMISSION UPDATE

Where to find it:
- Green + icon in the left Discord-style rail
- CREATE > Add real game map in the channel sidebar
- + Add real game map on the Discover Maps page
- + Add real map on the home page

How it works:
1. Sign in.
2. Open Add real game map.
3. Choose the game.
4. Paste the exact working code, ID, URL, world ID, Workshop ID, Realm code, or server address shown by the game.
5. Confirm that the reference is real and working.
6. Submit the listing.

The app rejects obvious placeholder/demo values and duplicate game+code combinations. New community submissions are not automatically marked verified. The first successful submission unlocks the creator console for that account.

This update preserves the existing instance/squadfinder.db when you copy your old instance folder into the new package.
