Publish MetaVerse SquadFinder for free

Supabase stores the permanent app data. Render runs the Flask website and supplies a trusted public HTTPS address.

1

Create a Supabase Free project

  1. Open the Supabase dashboard and create a project.
  2. Wait until it is ready.
  3. Open Connect and copy the Session pooler connection string.
  4. Replace the password placeholder with your database password.

Keep this string private. It gives server-level database access.

2

Prepare the database

Double-click:

PREPARE_SUPABASE_WINDOWS.bat

The wizard tests Supabase, creates the database tables, and can import your existing SQLite data. Choose the cleanup option to remove fake demo people, fake rooms, and fictional sample maps.

3

Upload this folder to a private GitHub repository

Do not upload .env, instance/, or certificate files. They are already excluded by .gitignore.

4

Create the free Render service

  1. In Render choose New → Blueprint.
  2. Select the GitHub repository.
  3. Render reads render.yaml.
  4. Paste the requested Supabase URL and administrator values.
  5. Deploy.
5

Open the public app

Render gives the app a public https://…onrender.com address with a trusted certificate. The old localhost “Not secure” warning does not apply to this public address.

After the first admin login, remove SQUADFINDER_ADMIN_PASSWORD from Render.

6

Optional domain and voice reliability

You can attach your own domain in Render. Browser voice works over public HTTPS, but users behind restrictive networks may require a TURN service; the optional variables are listed in .env.example.
